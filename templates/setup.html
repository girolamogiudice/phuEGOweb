Network Bundles

Each Zenodo archive contains one network support-data folder plus the small shared files required at the root of support_data. Use the install button to download and extract a bundle directly into the mounted support-data folder used by the running app.

Docker resolves this mounted folder for each user, so the setup process does not depend on a specific host path such as /Volumes/Untitled.
